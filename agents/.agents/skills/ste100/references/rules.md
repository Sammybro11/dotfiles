# STE100 rule reference

Vale runs the checks. This file explains what each finding means and how to
fix it without loss of the technical content.

| Rule | Level | Fix |
|---|---|---|
| `SentenceLength25` | error | Split the sentence. Descriptions allow 25 words. |
| `SentenceLength20` | warning | If the sentence is an instruction, split it at 20 words. |
| `Semicolon` | error | Write two sentences, or use "and" or "then". |
| `Contractions` | error | Write the words in full. |
| `Gerunds` | warning | Use the base verb, or a noun if you name a thing. |
| `Modals` | error | Use `can`, `will`, or `must`. Keep `may` only for permission. |
| `NounCluster` | error | Use a preposition or a verb to show how the nouns relate. |
| `PassiveVoice` | warning | Say who or what does the action. Use the active voice when you can. |
| `Ambiguity` | error | Give the condition, the value, or the list. |
| `BritishVariants` | error | Use American spelling. |
| `STE.Dict` | suggestion | The dictionary alternative is advisory, not a command. |

## Examples

- **Length:** `The operator opens the inlet valve and then starts the pump.`
  is 11 words. If a sentence passes 20 words, look for a clause to split.
- **Semicolon:** `Open the valve; start the pump.` becomes `Open the valve.
  Start the pump.`
- **Contraction:** `Don't touch the surface.` becomes `Do not touch the
  surface.`
- **Modal:** `The result should agree with the model.` becomes `The result
  must agree with the model.` if that is the requirement.
- **Noun cluster:** `qubit readout resonator calibration procedure` becomes
  `the procedure to calibrate the qubit readout resonator`.
- **Passive:** `The pulse is generated by the controller.` becomes `The
  controller generates the pulse.` Keep the passive when the actor is unknown:
  `The sample was cooled to 10 mK.`
- **Ambiguity:** `Set the value as required.` becomes `Set the value to 5 V.`
- **Gerund:** `The opening of the valve is necessary.` becomes `Open the
  valve.`
- **British:** `colour`, `normalise`, `behaviour`, `whilst` become `color`,
  `normalize`, `behavior`, `while`.

## Scope

- Lint prose, not code blocks, commands, paths, identifiers, or quoted text.
- Do not drop a number, unit, condition, or technical term to shorten a
  sentence.
- The dictionary suggestion can be wrong in context. Read the entry before you
  use it. `ste_lookup` returns the approved meaning and every alternative.
- A warning is not a defect. Fix it when the rewrite is clearer. Leave it when
  the passive or `-ing` form is the accurate choice.
